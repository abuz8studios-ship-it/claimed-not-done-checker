CLAIMED ≠ DONE Checker — Spec

Modular static files, unplugged: a pure Check Engine core, thin UI files, and an adapter seam with zero connectors today. No server, no database, no dependencies, works offline.

Data flow — one journey through the system

Boxes → engine → card. Nothing is stored; reload wipes everything. That is the product, not a limitation.

Components — each with its PRD home
  • Page Shell — header + Checker frame → prd.md > Screens and Layout
  • Claim / Evidence boxes — free text, no validation → Features and Behavior
  • Example buttons — full texts stored as JS strings → Features and Behavior
  • CHECK IT — runs engine, renders card → Features and Behavior
  • Check Engine — pure function, pinned rules + word lists → scope.md > Check Logic
  • Verdict card + checklist — hidden until first check → States and Boundaries
  • Meter + ledger stamp — Web Crypto SHA-256, display-only → Features and Behavior
  • Sample cards — hardcoded, display-only → Features and Behavior
